## Python Installation

This project uses Python to provide a GUI and export cheat codes. To run it, you must install Python for your system.

### Windows:

Look for installers of version 3.12 or version 3.13. During installation, make sure that you have Pip, Virtual Environment, and Tkinter, and perhaps PATH checked.

### Linux:

Some Distros may not have Python's Virtual Environment and Tkinter packages included in their installation. To check whether or not they're installed, list their package names in a package manager and check if they're marked as installed.

Example:
```
# Ubuntu
apt list python3-tk python3-venv
```
Any package that isn't marked as installed must be installed for the program to work.

Example:
```
# Ubuntu
sudo apt install python3-tk python3-venv
```

## Setting Up From Source
The LittleBigPlanet Popit Color Generator was tested on Python 3.12 (Windows 10/11) and Python 3.13 (Lubuntu 24.04) with CustomTkinter, PyYAML, and Pyperclip.

Although CustomTkinter is only meant to work in Windows or MacOS, a Ttk version will be made to support Linux out-of-the-box.

In order to install these libraries, create a virtual environment and activate it, and install them through this command:
```
# Ubuntu
pip install -r src/requirements.txt
# Windows
pip install -r src\requirements.txt
```
Then, you can open the GUI program:
```
# Ubuntu
python src/main.py
# Windows
python src\main.py
```
